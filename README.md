# NEON ASCENT — Eclipse Edition

Аркадный космический шутер на React + Vite + Canvas. Работает на ПК и телефонах, готов к публикации на Яндекс Играх.

## Как запустить и опубликовать

0. **Windows, проще всего:** дважды кликните `START.bat` — он сам установит зависимости, соберёт игру и откроет `dist\index.html` (нужен Node.js LTS с nodejs.org).
1. `npm install`
2. `npm run build` — создаёт **`dist/index.html`**. Это один полностью автономный файл (скрипты, стили и графика внутри), внешних запросов игра не делает.
3. Проверка локально: откройте `dist/index.html` двойным кликом (работает и с `file://`) или `npm run preview`.
4. Публикация на Яндекс Играх: упакуйте в zip **содержимое папки `dist`** так, чтобы `index.html` лежал в корне архива, и загрузите в консоль разработчика.

> ⚠️ Корневой `index.html` (рядом с `package.json`) — это **исходник**. Он ссылается на `/src/main.tsx` и без сборки показывает только экран «loading…». Если вы скачали проект и открыли именно его — соберите проект (шаг 2) и откройте `dist/index.html`. Игра сама подскажет об этом через 6 секунд.

## Настройка в консоли Яндекс Игр

- Таблица рекордов с техническим именем **`score`**.
- Категория «Аркады», **альбомная** ориентация.
- Включите рекламу (межстраничную и с вознаграждением) и облачные сохранения.
- Яндекс подключает SDK сам по относительному пути `/sdk.js`; игра загружает его только внутри iframe платформы.

## Тестовый режим

Кнопка «+50 000 💎» и бесплатные награды за рекламу работают **только** на `localhost`, при открытии файла с диска или с параметром `?dev=1`. Внутри Яндекс Игр они отключены.

## Управление

| | ПК | Телефон |
|---|---|---|
| Движение | WASD / стрелки | левый палец (стик) |
| Прицел и огонь | мышь, ЛКМ | правый палец (огонь автоматический) |
| Рывок / бомба / способность | Shift / E / Q | кнопки справа |
| Пауза | P / Esc | кнопка ⏸ |

Клавиши переназначаются в настройках (только на ПК). На телефоне игра просит повернуть экран в альбомную ориентацию.

## Структура

- `src/game/engine.ts` — игровой цикл, бой, прогресс, события
- `src/game/ai.ts` — ИИ врагов и боссов
- `src/game/hud.ts` — HUD на canvas (масштабируется под маленькие экраны)
- `src/game/yandex.ts` — обёртка Yandex Games SDK (реклама, облако, лидерборд)
- `src/game/save.ts` — сохранения и слияние с облаком
- `src/components/` — экраны интерфейса (меню, магазин, настройки)
